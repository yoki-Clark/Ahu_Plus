校园集市身份获取工具 - 使用说明
=================================

用途
----

Ahu_Plus 的校园集市使用独立 Bearer JWT，不使用安大统一身份认证。本工具在 Windows 本机识别电脑版微信中已经登录的集市身份，生成只能由 Ahu_Plus App 内扫码读取的 v2 专用二维码。

Token 等同于集市登录态。只在自己的电脑和账号上使用，不要发送给他人。

运行条件
--------

- Windows 10 或 Windows 11。
- 电脑版微信，且集市小程序已经登录。
- 首次准备运行环境时需要联网。
- 不需要管理员权限；代理兼容模式只安装到当前用户证书库。

使用步骤
--------

1. 双击“获取集市Token.cmd”。
2. 按窗口提示，在电脑版微信打开“校园集市 / 赞噢校园集市”小程序。
3. 在帖子列表下拉刷新，等待工具识别身份，最长 5 分钟。
4. 成功后工具会打开“集市身份导入二维码.png”。
5. 在 Ahu_Plus 的集市设置中选择扫描电脑二维码并确认导入。

Token 还会写入“我的集市Token.txt”作为本地应急备份，但不会自动复制到剪贴板，也不会生成可由其他 App 打开的深链。

两种工作模式
------------

工具同时跑两条捕获路径，谁先识别到身份即结束：

1. 内存扫描（已运行微信时自动启用，优先启动）

   只读扫描 WeChat / Weixin / WeChatAppEx 进程的可读内存区域，识别包含
   有效学校信息和过期时间的 JWT。不依赖代理、不受 TUN / 端口 / 证书影响，
   是 Clash TUN 模式下唯一有效的捕获路径。

2. 请求捕获（除非用户选 S 跳过，否则在内存扫描之后启动）

   启动本地 mitmproxy，仅允许 zxs-bbs.cn 任意子域的 HTTPS 请求被解密，
   并把本次运行生成的临时 CA 安装到 CurrentUser\Root。结束时会还原代理、
   按指纹删除证书，并删除临时 CA 私钥目录。代理监听端口会在 8080 起自动
   扫一个本机空闲端口，不再写死 8080。

启动前会检测 Clash / V2ray / sing-box 等可能以 TUN 模式接管系统流量的
代理软件；命中会暂停并提示：
  R = 重新检测    S = 跳过代理，只走内存扫描    C = 强行继续    Q = 退出
TUN 模式下代理捕获注定抓不到，选 S 只走内存扫描是最快的可行路径。

运行环境
--------

工具优先复用 Python 3.10 及以上和已安装的 mitmproxy、qrcode。系统有 Python 但缺组件时，会尝试用 --user 安装。没有可用 Python 时，才会在本目录创建 python/ 便携环境。

运行时下载源和版本由 run.ps1 定义。删除工具目录中的 python/ 即可移除便携环境；使用系统 Python 时，--user 安装的包不在本目录内。

失败排查
--------

- 未识别身份：确认使用电脑版微信，集市小程序已登录，并在帖子列表刷新；
  两条路径是并行的，刷新一次即可同时被内存扫描和请求捕获看到。
- 安全软件拦截：允许该工具只读访问微信进程；内存扫描被拦截不影响代理路径。
- 端口问题：代理端口会在 8080 起自动扫一个空闲端口；若仍提示代理启动失败，
  通常是 TUN 代理软件接管了流量或防火墙拦截了本机监听。
- 小程序显示网络错误 + 工具卡在“正在启动抓包代理…”：通常是上一次运行被
  强行关闭（X 掉窗口 / 任务管理器结束），系统代理残留指向 127.0.0.1 但无人
  监听。本次启动会自动检测并清掉这种孤儿代理；若仍出现，到 Windows
  “设置 -> 网络和 Internet -> 代理”手动关掉后重试。
- TUN 代理软件：Clash / V2ray / sing-box 等若以 TUN 或虚拟网卡模式运行，
  会在协议栈更下层拦截流量，导致请求捕获看不到集市请求。启动时工具会提示
  退出它们；选“C”强行继续通常仍会失败，请先退出或关闭 TUN 模式。
- TLS 失败：确认当前用户证书安装没有被安全策略拦截。
- 网络异常：正常结束工具会恢复原代理。若进程被强制终止，到 Windows“设置 -> 网络和 Internet -> 代理”恢复运行前的设置。
- 身份格式无法识别：集市后端可能已改变 JWT 结构，需要更新 catch_token.py 和 App 的 MarketApi 解析器。

隐私与清理
----------

- 代理模式通过 --allow-hosts 只解密 api.zxs-bbs.cn。
- 二维码由本机 qrcode 库生成，不调用在线二维码服务。
- 二维码内容是 `ahuplus.market.identity` v2 JSON，仍携带可导入的真实 Token；关闭工具窗口时会删除二维码文件。
- “我的集市Token.txt”不会自动删除，用完后应手动删除。
- .gitignore 已排除 Token、二维码、便携运行时和状态标记。
- 不要把“我的集市Token.txt”、二维码、.captured 或证书标记提交到仓库。

文件说明
--------

- 获取集市Token.cmd：普通用户入口。
- run.ps1：运行环境、内存扫描/代理选择、清理和提示。
- wechat_memory_token.py：已运行微信的只读内存扫描。
- catch_token.py：目标域请求头捕获、Token 文件和二维码生成。
- _mitmrun.py：mitmproxy 启动垫片。
- 使用说明.txt：本文件。
- python/：需要时生成的便携 Python。
- 我的集市Token.txt：成功后生成的敏感文件。
- 集市身份导入二维码.png：成功后生成，正常关闭窗口时删除。
