03 数据边界清清楚楚

你的校园数据，
应当由你掌握。

账号、密码、Cookie 与 Token 使用 Android Keystore 支持的加密存储；普通偏好和业务缓存保存在设备本地。应用禁用系统备份，也不会为了“方便”退回明文保存敏感信息。

  1. 01
    不做广告画像

    不开设第三方广告追踪，不用校园数据换取推荐流量。

  2. 02
    缓存不会因断网消失

    网络刷新失败时保留已有数据，避免临时波动变成空白页面。

  3. 03
    清理边界可以选择

    账号退出与全部数据清理分离，减少误删设置和课程备注。

04 安装之前，先把疑问说清楚

常见问题

重要校园信息仍应以学校官方渠道为准。遇到问题时，请勿在公开反馈中附带账号、Cookie、账单或其他个人数据。

这是安徽大学官方应用吗？

不是。安大+ 是独立开发的开源客户端，不代表安徽大学或任何接入的第三方平台。学校官方页面、记录、通知与规则具有优先效力。

必须登录校园账号才能使用吗？

不需要。天气、公告、帮助等内容可以匿名使用；课表、成绩、校园卡等个人校园数据只有在你主动登录后才会请求对应学校系统。

账号和密码保存在哪里？

账号、密码、Cookie 与 Token 使用 Android Keystore 支持的加密存储。加密存储不可用时，应用不会退回到明文持久化。

学习通、WeLearn 和 AI 功能会自动启用吗？

不会。第三方学习平台和外部 AI 属于可选能力，只有在你明确启用并发起对应操作时才会连接相关服务。

为什么数据偶尔与学校页面不同？

页面可能展示本地缓存，学校接口也可能维护、限流或临时异常。成绩、考试、考勤、余额和账单等重要信息请在官方渠道再次核对。

遇到问题或发现安全风险怎么办？

普通问题可前往 GitHub Issues；安全问题请使用代码托管平台的私密漏洞报告能力，或发送邮件至 2867299793@qq.com。
